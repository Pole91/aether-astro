# 🎮 Utbildningsspel för Barn (8-11 år)

En komplett webbapplikation med sex interaktiva utbildningsspel designade för barn mellan 8-11 år. Spelen kombinerar underhållning med lärande för att utveckla viktiga kognitiva färdigheter.

## ✨ Spel Inkluderade

### 🍎 Memory - Frukt Tema
- **Beskrivning:** Klassiskt memory-spel med frukt-emojis
- **Lär sig:** Minne, fokus, uppmärksamhet
- **Mekanik:** Hitta matchande fruktpar genom att vända kort
- **Feedback:** Försök-räknare, par-räknare och timer

### 🔍 Hitta Skillnaden
- **Beskrivning:** Visuell pussel-spel med två nästan identiska bilder
- **Lär sig:** Observation, uppmärksamhet, detaljseende
- **Mekanik:** Klicka på skillnaderna mellan två scener
- **Feedback:** Progress-indikator för antal hittade skillnader

### 🔢 Mattekviz
- **Beskrivning:** Snabba matteproblem med grundläggande aritmetik
- **Lär sig:** Matematik, snabbt tänkande, numerisk logik
- **Mekanik:** Välj rätt svar från fyra alternativ
- **Operationer:** Addition, subtraktion, multiplikation, division
- **Feedback:** Poäng-system, rätt/fel räknare

### 📚 Ord-Ordning
- **Beskrivning:** Svenska ord-spel där bokstäver måste ordnas rätt
- **Lär sig:** Ordförråd, stavning, svenska språk
- **Mekanik:** Klicka på bokstäver eller skriv direkt för att bilda ord
- **Innehål:** 10 olika svenska ord med ledtrådar
- **Feedback:** Progressiv difficultness med poäng-system

### 🌍 Geografi Quiz
- **Beskrivning:** Frågor om världens länder, städer och geografi
- **Lär sig:** Geografikunskap, världskunskap, kultur
- **Mekanik:** Multiple-choice frågor med omedelbar feedback
- **Innehål:** 10 frågor om världens geografi
- **Feedback:** Poäng-system och rätt/fel räknare

### 🧠 Logik Pussel
- **Beskrivning:** Varierade logiska utmaningar och pussel
- **Lär sig:** Logiskt tänkande, problemlösning, mönsterigenkänning
- **Pussel-typer:**
  - Sekvens-sortering
  - Form-räkning
  - Mönster-igenkänning
  - Matematik-lösning
  - Största/minsta-nummer
  - Matchande par
- **Feedback:** Progressiv difficultness med poäng-system

## 🛠 Installation & Körning

### Förutsättningar
- Node.js 16+ installerad
- npm eller yarn pakethanterare

### Installera Beroenden
```bash
npm install
```

### Starta Utvecklingsserver
```bash
npm run dev
```
Besök `http://localhost:3000` i din webbläsare.

### Bygga för Produktion
```bash
npm run build
```

### Förhandsgranska Bygget
```bash
npm run preview
```

## 📊 Forskning & Pedagogik

Spelen är designade baserat på vetenskaplig forskning om barns lärande:

- **Memory-spel:** Visat att förbättra fokus och arbetsminne
- **Observation-spel:** Utvecklar uppmärksamhet och snabbhet
- **Kviz-spel:** Gör lärande interaktiv och belönande
- **Logik-pussel:** Bygger problem-lösnings förmågor

Alla spel features:
- ✅ Omedelbar feedback
- ✅ Poäng-system för motivation
- ✅ Progressive difficultness
- ✅ Färgful och lekfull design
- ✅ Responsiv på mobil, tablet och dator

## 🎨 Design & Färger

- **Primär:** #FF6B6B (Röd)
- **Sekundär:** #4ECDC4 (Turkos)
- **Accent:** #FFE66D (Gul)
- **Dark:** #2C3E50 (Mörkblå)
- **Light:** #F8F9FA (Nästan vit)

Designen är barn-vänlig med stora, lätt-läsbar typografi och höga färg-kontraster.

## 📱 Responsiva Design

Spelen fungerar perfekt på:
- 🖥️ Desktop datorer
- 💻 Tablets
- 📱 Mobiltelefoner

Alla spel använder CSS Grid och Flexbox för optimal layout på alla skärmstorlekar.

## 🔒 Säkerhet & Integritet

- Ingen insamling av personlig data
- Ingen externa API-anrop
- Allt körs lokalt i webbläsaren
- Inga cookies eller tracking
- GDPR-kompatibel

## 📚 Teknologi Stack

- **Framework:** Astro 4.0+
- **Styling:** CSS3 (Grid, Flexbox, Gradients)
- **Interaktivitet:** Vanilla JavaScript
- **Responsivitet:** Mobile-first design
- **Iconografi:** Unicode Emojis
